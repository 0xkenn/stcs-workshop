# Styles

## Match CSS module names to their components
Use PascalCase for document CSS module filenames. Match component-specific styles to their component (DocumentUpload.module.css, DocumentPreviewDialog.module.css, DocumentManagementPage.module.css). Keep shared feature styles descriptive (DocumentActions.module.css, DocumentTheme.module.css). Update imports whenever a stylesheet is renamed.
